# Projeto Desafio LINQ-API c# JSON
Integrar projetos com aplicações externas, LINQ e criação de arquivos. HttpClient, uma importante biblioteca no C#
## Destaques do Projeto :pushpin:
-criar e manipular um modelo de músicas. Através da utilização de requisições, tratamento de exceções e desserialização de JSON, e exibir os dados no console de forma organizada.
Com base nos desafios propostos, listar gêneros musicais, ordenar artistas, filtrar músicas e criar uma lista das músicas preferidas. 
Criar arquivos JSON e conectá-los à plataforma Vercel para exibir a lista de músicas.
